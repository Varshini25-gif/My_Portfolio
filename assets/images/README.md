# Images Folder

This folder contains all images used in the portfolio website.

## Structure:
- `hero-image.svg` - Main hero section image
- `profile.jpg` - Your profile/about picture
- `project1.jpg` - Screenshot of project 1
- `project2.jpg` - Screenshot of project 2
- `project3.jpg` - Screenshot of project 3
- `favicon.png` - Website favicon

## Image Guidelines:
- **Hero Image**: Recommended size 800x600px (SVG preferred)
- **Profile Picture**: Recommended size 400x400px
- **Project Screenshots**: Recommended size 600x400px
- **Favicon**: 32x32px or 64x64px PNG

## Tips:
- Use optimized images to improve loading speed
- Consider using WebP format for better compression
- Use descriptive alt text for accessibility
